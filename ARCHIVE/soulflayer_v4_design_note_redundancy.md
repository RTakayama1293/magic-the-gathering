# Soulflayer V4 設計ノート：「止めても勝てない」冗長性の設計原則

> **起源**: Match 43 vs 赤黒ゴブリン（2026-02-19）
> G3で力線下から非墓地軸で逆転盤面を構築したが、Snoopのトップめくりから置物再供給＋サクり台起動で2点抜かれて敗北。
> 「アグロなのに器用すぎる」＝ **1つの軸を止めても別の軸でダメージが通り続ける冗長性** がゴブリンの強さの正体だった。

---

## ゴブリンが教えてくれた設計原則

### 原則：「軸を止めたこと自体がコストになる構造」

ゴブリンの各パーツは**同時に複数の軸に貢献**する：

| ゴブリン1体の役割 | 止めた場合の裏目 |
|-----------------|---------------|
| 戦闘打点 | — |
| Mischiefのドレイン弾（死亡誘発） | 全体除去で掃除 → 掃除した数だけ自傷 |
| Snoopの起動コスト/恩恵先 | Snoopが生きている限り山から再供給 |
| ロードの修正先 | 横に広がるほどP/T上昇 → 個別除去が追いつかない |

**相手のインタラクションが裏目になる** ＝ 受動的冗長性。こちらが何か仕掛けるのではなく、相手が対処しようとする行為自体がダメージ源になる。

### 対比：Soulflayer現行（V3.2）の冗長性

| 軸 | 依存リソース | 止められ方 | 止められた後 |
|----|------------|----------|------------|
| 1. KW魂剥ぎ | **墓地** | 力線/RiP/霊柩車 | 停止 |
| 2. カヴァエロコピー | **墓地** | 力線/RiP | 停止（素4/4は出せる） |
| 3. リアニ（ブリンガー） | **墓地** | 力線/RiP | 停止 |
| 4. 想起スキャム | 手札＋戦場 | 墓地追放（NDA前提なら墓地） | V3.2でNDA不採用のため実質休止中 |

**問題**: 表面上4軸だが、**軸1〜3が墓地という単一障害点を共有**。力線1枚で3軸同時停止。

### Soulflayerで「止めても勝てない」に近いもの（既存）

| 機構 | 仕組み | 限界 |
|------|-------|------|
| サイド変身 | 相手が墓地対策を積む → こちらが全変身 → 相手のSB枠が死ぬ | メタゲーム上の冗長性。1ゲーム内では機能しない |
| とんずら＋全体除去 | 自軍フェイズアウト → 掃除 → 自軍だけ残る | こちらから仕掛ける必要がある（受動的ではない） |
| 蝙蝠の追放裏目 | 蝙蝠除去 → 追放カードが手札に戻る | 相手が「除去しない」を選べば裏目が発生しない |
| カヴァエロ素出し＋鏡割り | 墓地不要の脅威軸。Match 43 G3で実証 | 4マナ＋寓話3章が必要。速度が遅く安定供給に欠ける |

---

## V4で検討すべき方向性

### 方向A：非墓地の第2ダメージエンジンを厚くする

**目標**: 力線/RiP下でも**メインプランに近い速度で脅威を展開**できる軸を持つ。

Match 43 G3が示したこと：カヴァエロ＋鏡割り（キキジキ）だけで逆転盤面まで行ける。問題は到達速度（T5以降）と供給安定性。

検討ポイント：
- カヴァエロ4枚は既にロック枠。素出し＝4マナ4/4コピーとしてのフロアが十分高い
- 鏡割り4枚もロック枠。第3章のキキジキが非墓地軸のエンジン
- **不足しているのは「カヴァエロでコピーして強い、墓地不要の脅威」**
- 現状の非墓地コピー先：相手のクリーチャー（状況依存）、蝙蝠（2/2飛行+ETB）、鏡割り裏面

### 方向B：墓地軸の中で「止めたこと自体がコスト」を作る

**目標**: 相手が墓地対策を使う行為自体にペナルティを課す。

例えば：
- 墓地追放に反応する誘発型能力（追放されるたびにドレイン等）
- 追放領域のカードを利用する能力
- → 現行パイオニアプールにこのような効果があるか要調査

### 方向C：軸間の独立性を高める

**目標**: 4軸の依存リソースを分散させる。

現状の依存マップ：
```
墓地 ← 軸1（KW魂剥ぎ）、軸2（カヴァエロコピー）、軸3（リアニ）
手札 ← 軸4（想起スキャム）
戦場 ← カヴァエロ素出し、鏡割り
```

理想：
```
墓地 ← 軸1（KW魂剥ぎ）
手札 ← 軸2（新設？）
戦場 ← 軸3（カヴァエロ＋鏡割り）
??? ← 軸4
```

軸2を「手札から直接唱えて強いカード群」にすれば、墓地と戦場の両方を止められても手札から脅威が飛ぶ。ただしこれはミッドレンジ的な発想で、魂剥ぎのアイデンティティ（墓地利用）と枠が食い合う。

## 未解決の問い

1. **カヴァエロ素出しの速度をどう上げるか？** — 4マナは対アグロでは遅い。3マナ以下の非墓地脅威はあるか？
2. **鏡割りの第3章（キキジキ）の信頼性** — 寓話がなければ非墓地軸が起動しない。寓話への依存度を下げる方法は？
3. **「止めたら裏目」構造をパイオニアのカードプールで実現できるか？** — 墓地追放に反応するカード、追放領域参照カードの調査が必要
4. **冗長性を高めると各軸が薄くなるトレードオフ** — ゴブリンは全カードがゴブリン部族で自動的に全軸に貢献する。Soulflayerは各軸のカードが別々なので、冗長性を上げるほどデッキが散らばるリスク
