# Soulflayer V4 設計ドラフト：デーモン変身構造（v3）

> **設計起点**: V4設計ノート（冗長性の設計原則）+ 過去の相棒実験10種の教訓
> **コンセプト**: G1は魂剥ぎ＋不浄な別室のデーモンボーナスで墓地デッキとして勝つ。G2-3は墓地対策を誘った上でドロス＋変態変異のデーモンパッケージに変身して「すかす」。
> **最大の構造的強み**: 魂剥ぎ自体がデーモンなので、変身後も4マナ4/4デーモンとして残留し別室のドレイン条件を満たし続ける。カードを抜かずにプランが切り替わる。

---

## 1. 根源的欲求と設計原則

### やりたいこと
> 魂剥ぎという強烈な墓地依存デッキで墓地対策を誘い、サイドでそれをすかす。

### すかし方の3分類

| 型 | 仕組み | 相手の墓地対策は… | 採用 |
|----|--------|-----------------|:--:|
| ①追放payoff | 追放枚数が燃料になる | こちらの燃料 | △ |
| ②コンボで勝つ | 墓地不要の2枚コンボで即勝ち | **完全な死カード** | **◎ 採用** |
| ③ミッドレンジ | 高品質単体カードで殴り合う | 空振り | △ |

→ V4は②を採用。相手のSB枠を最も無駄にする構造。

### 過去の相棒実験から得た教訓

| 教訓 | 由来 |
|------|------|
| G1で追放payoffを匂わせると墓地対策の誘導が鈍る | ケトラモーズの実戦経験 |
| メインの「すかし用カード」はG1で存在を隠すべき | 同上 |
| 墓地依存の第2軸は力線1枚で同時停止する | パルヘリオン+脂牙 |
| コンボパーツが両方素引きで仕事をすること | ドロス+別室の評価 |
| 1枚のカードが複数軸に貢献する冗長性が理想 | ゴブリンの設計原則 |

## 2. 2プラン構造

```
G1: 魂剥ぎ（KWフィニッシャー）＋不浄な別室（ドロー＋デーモン時ドレイン2）
     → 相手に「墓地デッキ」と認識させる
     → 別室は「変なエンチャント」程度の印象。墓地対策の投入判断を変えない

G2-3（墓地対策あり）: KWドナー＋掘りを抜く → ドロス＋変態変異＋変わり谷を投入
     → 魂剥ぎは4/4デーモンとして残留。デーモン軸で殴り＋ドレインで勝つ
     → 相手の墓地対策は全カード死札

G2-3（墓地対策なし）: 微調整のみ。G1プランを継続
```

### マルパルとの構造比較

| 比較軸 | マルパル（パルヘリオン→デーモン） | 魂剥ぎV4（魂剥ぎ→デーモン） |
|--------|-------------------------------|---------------------------|
| G1のカードが変身後に貢献 | × パルヘリオンはデーモンプランにゼロ | **◎ 魂剥ぎ＝デーモン。別室のドレイン条件を満たす** |
| 変身の重さ | 10枚入替（ほぼ別デッキ） | 15枚入替だが共通基盤が厚い |
| 変身後の脅威密度 | デーモンパーツのみ | デーモン＋魂剥ぎ＋寓話キキジキ |

## 3. 不浄な別室のメイン投入根拠

### カードテキスト

**Unholy Annex / 不浄な別室** {2}{B} エンチャント — 部屋
> あなたの終了ステップの開始時に、カード１枚を引く。あなたがデーモンをコントロールしているなら、各対戦相手はそれぞれ２点のライフを失い、あなたは２点のライフを得る。そうでないなら、あなたは２点のライフを失う。

**Ritual Chamber / 祭儀室** {3}{B}{B} エンチャント — 部屋
> あなたがこのドアを開放したとき、飛行を持つ黒の6/6のデーモン・クリーチャー・トークン１体を生成する。

### G1での動き

| ターン | 盤面 | エンド時 |
|--------|------|---------|
| T3 | 別室開放 | ドロー＋**自分2点ロス**（デーモンなし） |
| T4 | 魂剥ぎ着地（デーモン） | ドロー＋**相手2点ロス＋自分2点ゲイン** |
| T5 | 殴り＋（余裕あれば祭儀室開放） | ドロー＋ドレイン2＋6/6飛行トークン |

- 毎ターンドロー＋ドレイン。凝視/回収とは別種のアドバンテージエンジン
- T3自傷2点は対アグロでリスク。T4魂剥ぎ（絆魂）着地が前提

### 変身後での役割

- ドロスの魔神＝デーモン → ドレイン起動
- 魂剥ぎ素キャスト＝デーモン → ドレイン起動
- 祭儀室の6/6トークン＝デーモン → ドレイン起動
- 変わり谷（クリーチャー化中）＝デーモン → ドレイン起動
- 殴れない盤面膠着でも毎ターン2点ドレイン＋1ドロー

## 4. 変態変異コンボの成立補助

### 変態変異の弱点
相手にクリーチャーがいないと貼れない。UWコントロール等でクリーチャーが少ない対面で腐るリスク。

### 白鳥の歌（Swan Song）{U}
インスタント/ソーサリー/エンチャントを打ち消す。コントローラーに2/2飛行鳥トークンを与える。

**二重用途**:
1. コンボ保護（相手の除去/カウンターを打ち消す）
2. 変態変異の対象生成（相手の呪文を打ち消す→鳥トークン→変態変異→ドロスコピー→油0即死）

### 贈呈系・トークン付与系カード（要調査）
相手にクリーチャーやトークンを渡す効果全般。白鳥の歌以外の候補を広く探す。

**Pioneer法的の候補**:
- 禁忌の果樹園 (Forbidden Orchard) — **要リーガル確認**。タップで1マナ＋相手に1/1スピリット
- 降格の短剣 (Dowsing Dagger) — ETBで相手に0/2植物トークン2体→攻撃当てたら土地に変身
- 跳ね橋トロール (Clackbridge Troll) — ETBで相手に0/1ヤギ3体。5/5トランプル速攻デーモン(!!)
- 霜剣山のチャネル — 相手に1/1は渡さない（自分にトークン）。対象用途には不可
- その他ブルームバロウ以降の「贈呈」メカニズム持ちカード — 要網羅調査

## 5. ロック/可変マップ V4

### ロックの判定基準
> **ロック＝枚数・採否が環境に依存しない。どんなメタでも動かさない。**

V3のロック54枚→V4は27枚。G1とG2-3で別の顔を持つデッキなので「どちらでも不動」は少なくて当然。

|--------|------|:--:|:--:|
| **CORE-LOCK** | 両プラン不動 | ✓ | ✓ |
| **GY-LOCK** | G1墓地プラン不動 | ✓ | OUT |
| **LAND-LOCK** | マナベース不動 | ✓ | ✓（一部入替） |
| **VARIABLE** | 環境・枚数で動く全カード | 選択 | 選択 |
| **SB候補** | SB枠の候補群 | — | IN |
