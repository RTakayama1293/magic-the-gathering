## v3からの変更点と理由（2026-02-15更新）

| 変更 | 理由 |
|------|------|
| 幽愁3rd（S1）→ 羅利骨灰（S1） | 置物対策を維持しつつ、キッカーでシェオル/ドロス/侵入者を追放可能に。G1構造的不利だった黒系ミッドレンジG2-3の回答を追加 |

### 羅利骨灰 vs 幽愁3rd：なぜ入れ替えたか

| 比較項目 | 幽愁3rd (Wistfulness) | 羅利骨灰 (Tear Asunder) |
|---------|----------------------|------------------------|
| 置物破壊 | ✓ 想起{G}{G}で追放 | ✓ {1}{G}で破壊 |
| クリーチャー/PW対処 | ✗ | **✓** キッカー{2}{B}{G}で追放 |
| スピード（タイミング） | ソーサリー（想起）/ インスタント（{U}{U}ルーティング） | **インスタント** |
| ルーティング | ✓ {U}{U}で2ドロー1捨て | ✗ |
| 素出しボディ | ✓ 6/5 | ✗ |
| 色要求 | {G}{G}（想起）= 緑ダブル | {1}{G}（基本）/ {2}{B}{G}（キッカー） |
| RiP下での動作 | ✗（想起→追放に置換） | **✓**（墓地非依存） |

**結論**: 幽愁3rdのルーティング＋6/5ボディを失うが、「置物対策と確定除去の1枚二役」がそれを上回る。特にG2-3でシェオルを追放できるのは構造的な穴を埋める。

## 多軸構造：4つの勝ち手段

### 軸1：魂剥ぎ — キーワード泥棒（メインプラン）

墓地のクリーチャーからキーワード能力を獲得した4/4。最速T2着地。

**キーワード供給マップ：**

| 供給源 | 枚数 | 渡すキーワード |
|--------|------|----------------|
| 縞カバの河蛇 | 4 | 呪禁 |
| アトラクサ | 3 | 飛行, 警戒, 接死, 絆魂 |
| サムト | 3 | 速攻, 二段攻撃, 警戒 |
| 末裔 | 1 | 飛行, 先制攻撃, トランプル, 絆魂, 速攻 |
| 大洞窟の蝙蝠 | 2 | 飛行, 絆魂 |

**絆魂カウント：6枚**（アトラクサ3 + 末裔1 + 蝙蝠2）
**飛行カウント：6枚**（アトラクサ3 + 末裔1 + 蝙蝠2）

### 軸2：カヴァエロ — 墓地コピー（4マナの柔軟な脅威）

4マナで墓地のクリーチャーを4/4コピーとして戦場に出す（元カードは追放）。

**主要コピー先：** アトラクサ（ETB手札補充）、サムト（速攻8点）、運び手（軸3起動）、相手クリーチャー（シェオルコピー等）

### 軸3：カヴァエロ + 運び手 — リビングエンド

メイン運び手1枚。積極的に狙う軸ではなく「掘りで落ちたら使える」ボーナス軸。

### 軸4：想起 + とんずら — フェイズアウト救出プラン

v2の「想起スキャム（NDA）」に代わる新しい軸4。想起エレメンタルのETBを使いつつ、とんずらでフェイズアウトさせて生け贄を回避する。

| 想起元 | 想起コスト | ETB効果 | とんずら後の盤面 |
|--------|-----------|---------|-----------------|
| 欺瞞（{U}{U} or {B}{B}） | 2マナ | バウンス or ハンデス | 5/5 + +1/+1カウンター |
| 幽愁（{G}{G} or {U}{U}） | 2マナ | 置物追放 or ルーティング | 6/5 + +1/+1カウンター |

**NDAとの決定的な違い：**
- フェイズアウトは**墓地を経由しない** → インスタント墓地追放で潰されない
- RiP/力線下でも動作する
- 魂剥ぎ/カヴァエロの保護にも使える（NDAは死亡前提で脅威保護に不適だった）
- 想起と無関係に、着地した魂剥ぎを評決/告別から守る1マナの保険として機能

**制約：** とんずらは{U}必要。想起{U}{U} + とんずら{U}を同ターンに唱えるには青3マナ必要で、基盤は厳しい場合がある。

## 対策耐性の構造

| 相手の対策 | 止まる軸 | 残る軸 |
|-----------|---------|--------|
| 無認可霊柩車（選択追放） | 魂剥ぎ（部分的） | カヴァエロ、リビエン、方程式でキャスト時カウンター、**羅利骨灰で破壊** |
| 安らかなる眠り（全墓地追放） | 魂剥ぎ、カヴァエロ、リビエン | 幽愁{G}{G}で追放、方程式でキャスト時カウンター、**羅利骨灰で破壊** |
| 墓地の侵入者（毎ターン1枚追放） | 魂剥ぎ（遅延） | カヴァエロ（4マナで即コピー）、想起+とんずら、**羅利骨灰キッカーで追放** |
| 虚空の力線（相手墓地常時追放） | 魂剥ぎ、カヴァエロ、リビエン | 幽愁{G}{G}でエンチャント追放、想起+とんずら、**羅利骨灰で破壊** |
| 単体除去（Fatal Push等） | — | 魂剥ぎ（呪禁）、とんずらで保護 |
| 全体追放（評決・告別） | 魂剥ぎ（呪禁無視） | とんずらでフェイズアウト、カヴァエロ再展開 |
| 布告除去（ヴェリアナ等） | 魂剥ぎ（呪禁回避不可） | 横並び展開。蝙蝠が布告吸収 |
| シェオルドレッド（接死絆魂+ドロー課税） | 魂剥ぎ（4/4同士で相打ち） | 苦勝で破壊、カヴァエロコピー、**羅利骨灰キッカーで追放** |

**v3.1の新しい対策レイヤー：**
- **羅利骨灰**：霊柩車/RiP/力線を破壊（事後対処）+ シェオル/侵入者を追放（確定除去）
- **方程式の改変**：霊柩車/RiP/力線をキャスト時にカウンター（事前対処）
- **とんずら**：着地済み脅威の保護 + 想起救出（事後対処）

## サイドボード設計思想

### 変身深度の3段階（v3.1更新）

v3でNDA/スキャムが廃止されたため、「全変身」の定義が変わる。魂剥ぎを抜く深い変身時は、とんずら＋想起＋ハンデス＋カヴァエロで戦う。

| 深度 | 対象 | OUT候補 | IN候補 |
|------|------|---------|--------|
| **変身なし** | イゼプロ、赤単 | 運び手、蛮行 | プッシュ3rd、危難、選別 |
| **部分変身** | ゴルガリ、セレズニア | 魂剥ぎ2 + 河蛇2 | とんずら、ハンデス、方程式、**羅利骨灰** |
| **全変身** | UWコン、オルゾフ | 魂剥ぎ4 + 河蛇4 | とんずら3、ハンデス全量、方程式2、幽愁3rd→**羅利骨灰** |

### 偵察→調整の原則（v2から継続）

G2でサイドの深さを仮決定し、G2で相手の墓地対策量を偵察、G3で変身深度を再調整する。

## プレイング指針：5つの原則（v2から継続）

1. **脅威逆算** —「何に殺されるか」を先に考える
2. **軸選択** —「今このゲームで生きている軸」を1つ選ぶ
3. **順序** —「情報を先に取り、不可逆な行動を後にする」
4. **資源管理** —「希少資源を特定し、それを守る」
5. **マリガン基準** —「T4までに1軸が稼働するか」

詳細は soulflayer_framework.md を参照。
