# Soulflayer V4「変態魔神」デフォルト構成

> **コンセプト**: G1は魂剥ぎ＋不浄な別室で墓地デッキとして勝つ。アグロには除去＋KWドナーの壁で圧倒。G2-3は墓地対策を誘った上でドロス＋変態変異のデーモンパッケージに変身して「すかす」。
> **最大の構造的強み**: 魂剥ぎ自体がデーモンなので、変身後も別室のドレイン条件を満たし続ける。

### IN 15枚: SB全投入

### 凝視3枚残しの根拠
変態変異を引きたい変身後はトップ操作が最重要。力線下でも「上3枚見て不要牌をボトムに送る」カード選択は機能する。回収は力線下で完全な死札だが、凝視は違う。

### 魂剥ぎ1枚カットの根拠
墓地対策下の魂剥ぎは探査不可→{4}{B}{B}の6マナ4/4バニラ。デーモンタイプで別室ドレインは満たすが、ドロス4枚＋変わり谷2枚で十分なデーモン密度を確保済み。3枚あれば引ける確率は十分。

## v3→v4 主要変更サマリ

| 項目 | v3 | v4 | 理由 |
|------|-----|-----|------|
| カヴァエロ | 4（ロック） | **0** | コピー軸→デーモン変身軸へ。墓地依存の第2軸は力線で同時停止する問題を解消 |
| ブリンガー | 1 | **0** | 想起リアニ軸は変身構造と枠競合 |
| 幽愁 | 2メイン | **0** | 力線は変身ですかす。割る必要がない |
| 才気ある霊気体 | 0 | **2** | {B}{B}2/3接死絆魂。T2壁＋最強KWペア。SB後も残留 |
| 不浄な別室 | 0 | **2+1SB** | V4の核。ドロー＋ドレイン |
| ドロスの魔神 | 0 | **4 SB** | 変身の主砲 |
| 変態変異 | 0 | **2 SB** | 相手クリーチャー→ドロスコピー→即死 |
| ウィザコマ | 0 | **2** | メインから置物破壊。切削＋土地回収も |
| 蛮行 | 1-2 | **0** | ウィザコマに枠を譲る |
| 蝙蝠 | 2-3 | **2** | サムト3に枠を回す |
| サムト | 3 | **3**（維持） | 速攻+二段の決定力。瞬速壁 |
| Push | 3-4 | **3** | 回収3確保のため1枠譲る |
| 変わり谷 | メイン1 | **SB 2** | G1で情報を隠す |
| SB変身OUT | 土地2枚含む | **土地抜かず。回収3+魂剥ぎ1** | 墓地対策下の魂剥ぎは6マナバニラ |
