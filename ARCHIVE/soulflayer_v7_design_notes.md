# Soulflayer V7 設計ノート — 抽象的知見まとめ

> このドキュメントはV6→V7移行にあたっての設計哲学と判断基準を記録したもの。
> 特定カードの採否ではなく、構造的原則と判断軸を保存する。
> カード詳細の議論は別途進める。

---

## 1. フレームワークが示したV6への根本批判

### 「育てる」vs「点火する」

魂剥ぎの本来の強さは**同ターン内で墓地を満たして即着地する**ことにある。  
V6のルーティング設計（繕い＋耽溺の複数ターン積み上げ）はこの強みを犠牲にしており、「育てる」型に近づいていた。  
Hogaak・Hollow Oneが対策に強かった本質も「着地直前に一気に完結」にあった。

**V7の目標：同ターン完結設計への回帰。墓地が「満たされている時間」を最小化する。**

### 変身SBへの評価の更新

変身SBの問題は「変身先の質」ではなく「必要スロット数」にある。  
V6の非墓地勝ち筋（記念碑＋ケトラモーズ）は実質5〜7枠でインフラを共有しており、  
Legacy Reanimatorが成功した「3〜4枠＋インフラ共有」の条件に近く、変身としては許容範囲。  
問題は速度——T5-6着地が設計目標になったことで「点火」型から外れた。

## 2. V7の中心的設計転換

### 速度の再定義

| V6 | V7目標 |
|---|---|
| T5-6 干渉→安全着地 | T3-4 同ターン完結着地 |
| 壁型（除去不能で詰む） | 即殺型（殴り切るターンを最短化） |
| 速攻は「あれば速い」ボーナス | 速攻を勝利条件に組み込む |

### T3 vs T4 の逆転

直感に反するが**T3着地より T4即殺が速い**ケースがある。

- T3着地・8点クロック → 3ターン後（T5）にキル
- T4着地・20点超 → **同ターンキル**

「何ターンで着地するか」ではなく「何ターンでゲームが終わるか」で速度を測る。  
速攻付与の全軍バフが絡む場合、リアニメイトでの一斉攻撃がこの条件を満たす。

## 3. コンボ軸の構造的評価

### 変身（リアニメイト型）が機能する条件

Legacy Reanimatorの事例から導いた普遍的条件：

1. **変身後フィニッシャーはデッキに既に入っている**（専用パーツを追加しない）
2. **変身スロットが3〜5枠以内**
3. **メインプランのインフラを変身プランが共有している**（同じ掘りエンジンで両方落ちる）

この3条件を満たす変身軸はV7で正当化される。満たさない変身は稀釈コストが高い。

### 対称効果への対策

全体リアニメイト系のカードは**対称効果を持つものが多い**。  
相手のGYに何があるか・自分のGYの量が相手を上回るか、が勝敗を左右する。  
「GYを点火する」設計（積み上げ時間を短くする）はこの対称性リスクを下げる副次効果もある。

## 4. キーワードドナー評価軸の更新

### 単体性能 vs コンボ貢献の両評価が必須

V7のKWドナー候補を評価する際は以下の2軸で見る：

| 評価軸 | 内容 |
|---|---|
| **魂剥ぎKWドナーとして** | 何KWを供給するか。呪禁・速攻・二段攻撃の優先度が最高 |
| **コピー対象として** | カヴァエロでコピーしたとき何ができるか。単体で強いか |

両方に貢献するカードが最も効率的。片方だけのカードは枠を取りすぎる。

### KW優先順位（V7での再定義）

| 優先度 | KW | 理由 |
|---|---|---|
| **最高** | 速攻 | T4即殺を実現するために必須 |
| **最高** | 呪禁 | 除去耐性の根幹。代替不可 |
| **高** | 二段攻撃 | 打点倍増。速攻との組み合わせが最強 |
| **高** | 先制攻撃 | 二段攻撃に準じる。ブロッカー排除 |
| **中** | 飛行 | ブロックされない。速攻と組み合わせで即殺 |
| **中** | 絆魂 | ライフレース安定。速攻型ではやや優先度低下 |
| **低** | 破壊不能 | V6では主力だったが速攻型では「1ターン待てない」 |
| **低** | 警戒・トランプル | おまけ |

## 5. 色基盤の選択基準

### V6（白あり）→V7（緑あり）の転換理由

V6でエスパーを選んだ理由は「白の追放除去・全体除去・詩句」だった。  
V7で緑を戻す理由は「速攻付与の全軍バフ・自然の主張（置物対策）・掘りエンジンの強化」。

白を抜くことで失うもの：
- 追放除去（消失の詩句）
- 打ち消されない全体破壊（至高の評決）
- MV2以下全追放（ピナクルの星檻）
- 繕いのFBによるディスカード連鎖（記念碑との相性）

この損失が速度向上で補えるかがV7の中心的賭け。

### 土地枚数の設計原則

高マナコストのカードを複数採用するデッキでは**土地23〜24枚が基準**。  
20枚は明らかに不足。掘りエンジンが豊富でも土地不足は「掘れない展開」でゲームを失う。

## 6. サイドボード哲学の確定（フレームワーク結論）

### 変身より対策除去を優先する

墓地対策がゲーム開始時にある確率は25〜33%（SB2〜3枚想定）。  
過半数のゲームは対策なしで始まる。変身プランへの多額投資を正当化しない。

**推奨SB構成の優先順位：**

1. **プリエンプティブ妨害**（対策を手札から事前に抜く）— 2〜3枠
2. **解決済み対策の除去**（着地した置物を割る）— 2〜3枠  
3. **スタック上の保護**（カウンターで守る）— 1〜2枠
4. **残り枠**で対面別ツール — 7〜9枠

変身専用スロットはこの枠の中で「インフラ共有の条件を満たす場合のみ」3〜5枠まで。

## 7. 未解決の中心的問い

フレームワークが「データなしでは答えられない」と明示した問い：

> **エネーブラー最小枚数とKWドナー構成のトレードオフ**

同ターン完結着地を安定させるために何枚のエネーブラーが必要か。  
多すぎればバリューデッキ化（「育てる」型に戻る）。  
少なすぎれば失敗率が上がる。  
この答えは実戦データからしか出ない。**V7の10〜15マッチが終わった時点で改めて検証する。**
