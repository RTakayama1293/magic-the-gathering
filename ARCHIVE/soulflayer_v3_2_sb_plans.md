# Soulflayer v3.2 — 構築変更 & 対アグロSBプラン

## v3.1 → v3.2 変更サマリー

| 変更 | v3.1 | v3.2 | 理由 |
|------|------|------|------|
| プッシュ配置 | M2/S1 | **M3** | メインの除去密度を上げてG1対アグロ改善 |
| 欺瞞 | M1 | **S1** | 5マナ素出し/想起1:1はメインに置くほどの汎用性がない。プッシュ3rdの枠確保 |
| 選別の儀式 | S1 | **不採用** | {2}{B}{G}はアグロに間に合わない。寓話/蝙蝠を巻き込むリスク |
| 危難の道 | S1 | **S2** | {1}{B}{B}でMV2以下クリーチャー限定。こちらのカヴァエロ/寓話裏面を温存 |

**設計方針**: メインの対策は1マナに統一（プッシュ）。2マナ以上のインタラクションは自分の掘り/展開と競合するため、サイドの「劇的なカード」（危難）で補完する。

### マリガン基準（対モノレッド固有）

| 手札 | 判断 | 理由 |
|------|------|------|
| 土地2 + Push + 掘り | **即キープ** | T1 Push or 凝視 → T2-3展開。最良パターン |
| 土地2 + 掘り + 勝ち手段（除去なし） | **マリガン** | 除去なしは死。M#28の教訓 |
| 土地2 + Push×2 + 掘りなし | **条件付き** | 相手を止められるがこちらの軸が起動しない。6枚以上なら渋々キープ |
| 土地2 + 危難 + 凝視 | **キープ** | T1凝視→T3危難で盤面リセット→T4魂剥ぎが理想 |
| 土地1 + 回収 + Push | **条件付き** | 回収で土地拾える。リスクあるが6枚以下ならキープ |

**鉄則: 除去0の手札は相手がアグロの時点でマリガン。**

### ゲームプラン

```
T1: 凝視 or Push（相手がT1速槍なら即Push優先）
T2: Push/蛮行で盤面維持 + 回収で掘り
T3: 危難で盤面リセット or 方程式構え
    → リセット後にマナが余ればFB凝視
T4: 絆魂(+α)魂剥ぎ着地 → ライフ回復開始
T5+: 殴りながらカヴァエロで追撃
```

**分岐点: Nemesis/Lynx が出てきたら**
- 方程式を構えていれば → キャスト時にカウンター
- 場に出てしまったら → Push(revolt) or 苦勝で確定除去。放置は絶対NG（絆魂封じ）
- 危難はNemesis(MV3)/Lynx(MV4)に当たらない → **方程式が唯一の事前対処、苦勝が事後対処**

### モノレッドとの戦略的違い

**1. 危難のタイミング**
- モノレッド: T3に撃って全滅させたい。相手は再展開が遅い
- イゼプロ: **T3に撃っても1マナ呪文連打で即トークン再生成される可能性あり。** 危難は「Cutterが場にいる状態」で撃つのが最大効率。Cutterごと流してからこちらが蓋をする

**2. 方程式の使い方**
- モノレッド: Nemesis/Lynx（大型脅威）をカウンター
- イゼプロ: **Cutter/才能（エンジン）をカウンター。** エンジンを止めれば後続が細くなる。個別クリーチャーより才能/Cutterが優先

**3. 蝙蝠の追放先**
- モノレッド: バーン呪文を追放（ライフ保全）
- イゼプロ: **嵐追いの才能 or Cori-Steel Cutter を追放。** 才能はリソースエンジン、Cutterはトークンエンジン。Basicsは魂剥ぎ/カヴァエロに撃たれても0.5:1なので低優先

**4. Boomerang Basics の正しい評価**
- 魂剥ぎ/カヴァエロへのバウンスは**脅威ではない**。魂剥ぎは探査で{B}{B}再キャスト、カヴァエロは再ETBでコピー再選択。相手にとって0.5:1の損な交換
- **本当の脅威: 相手が自分の才能/Cutterをセルフバウンスして再利用すること。** 才能再設置でエンジン再起動、Cutter再キャストでETB再誘発
- 方程式はBasics対策に温存する必要なし → **Cutter/才能のキャスト時に全力で使う**
- 魂剥ぎも温存不要。出せるなら即出す

### ゲームプラン

```
T1: 凝視 or Push（速槍/魔道士即除去）
T2: Push/蛮行でCutterを最優先除去 + 回収
T3: 危難で残党一掃 or 方程式構え（才能/Cutterの再展開に備える）
T4: 絆魂(+α)魂剥ぎ着地
    → 方程式はCutter/才能の再キャスト阻止に使い切ってOK
T5+: 魂剥ぎクロック + カヴァエロ追撃
```

## 共通の注意点（モノレッド / イゼプロ共通）

### 合流点のライフコスト
対アグロでは合流点のアンタップインが実質バーン。可能な限りタップインか他の土地を優先。ただしT2にPushを構える必要がある場合はアンタップインも許容。

### 蝙蝠の役割変化
対アグロでは「ハンデス」より「1/1飛行絆魂ブロッカー」の価値が高い。T2蝙蝠→速槍をブロック→1点回復+相打ちでも、1ターン稼いで1点回復は対アグロで十分な仕事。ETBのハンデスは「バーン呪文を追放してライフ保全」として使う。

### 河蛇OUTの論拠
- 呪禁がモノレッドにほぼ無意味（火力は顔にも飛ぶので対象除去に困ってない）
- 呪禁がイゼプロにも価値が薄い（火力+バウンスが主体。Basicsで魂剥ぎをバウンスされても探査再キャストで問題なし）
- 7マナ素引きが完全な死札
- 呪禁なし魂剥ぎに火力/除去を撃たせる = **顔に飛ばない分だけ実質ライフゲイン**
- 絆魂供給は残りドナー6枚で十分に維持

### 方程式の構え方
{1}{U}構えはT2では自分の動き（回収{B}{G}）と競合する。理想的には：
- T2: 回収 or Push（盤面対処優先）
- T3: 方程式構え or 危難（盤面状態で判断）
- T4以降: 魂剥ぎキャスト後に方程式を温存（Basicsやバーンへの保険）

### 勝利条件の明確化
**「絆魂魂剥ぎの着地」が勝利条件。** それまでの全行動はこの着地を可能にするための時間稼ぎ。
- 呪禁は不要（河蛇OUT前提）
- 絆魂は**必須**（ライフレース逆転がこのマッチアップの唯一の勝ちパターン）
- 飛行は嬉しい（地上のブロッカーを飛び越える）
- **最低限: 絆魂のみの4/4でも着地すれば勝てる。理想形を待って死なない。**
