# Soulflayer プレイング指針フレームワーク

対戦中の判断を導く5つの抽象原則と、サイドボード・マリガンの意思決定構造。
パターン暗記ではなく、**未知の局面でも論理的に正解を推論するための思考フレーム**。

---

## 原則1：脅威逆算 —「何に殺されるか」を先に考える

相手のキルターン・キルルートを特定し、**逆算して**自分の行動を決める。

| 相手の速度 | 代表デッキ | こちらの優先行動 |
|-----------|-----------|----------------|
| 4キル | イゼプロ、赤単 | T3-4の生存が最優先。**掘りより除去が先** |
| 6-7キル | ゴルガリ、UWコン | 掘り優先でフィニッシャーの質を最大化 |
| コンボ | アブパル、ロータス | 妨害の着地タイミングがゲームを決める |

**チェック**：「あと何ターン生きられるか」→ その中で完成できる軸はどれか → 行動決定

**実例**：Match 12 G3 — 回収でアンタップイン土地を取ったのが敗因。残りターン数を逆算すれば、モンクと相撃ち→1ターン生存→鮮麗素出しのラインが見えた。

## 原則2：軸選択 —「今このゲームで生きている軸」を1つ選ぶ

4軸のうち、1ゲーム中に動かせるのは1〜2本。**最も完成に近い軸にリソース集中**。分散投資しない。

### 軸選択チェックリスト（ターンごとに更新）

| 状態 | 選ぶ軸 |
|------|--------|
| 墓地に河蛇＋KWドナー、手札に魂剥ぎ | 軸1（魂剥ぎ） |
| 墓地にアトラクサ/サムト、手札にカヴァエロ | 軸2（カヴァエロコピー） |
| 墓地に運び手＋複数クリーチャー、手札にカヴァエロ | 軸3（リビエン） |
| 手札にNDA＋想起エレメンタル | 軸4（スキャム） |
| 複数軸が半端 | **掘りで1つを完成させる** |

**実例**：Match 10 G1 — 魂剥ぎが除去された直後、凝視でカヴァエロ発見→軸1から軸3（リビエン）にスムーズに切り替えて勝ち。軸選択は固定ではなく毎ターン更新。

## 原則3：順序 —「情報を先に取り、不可逆な行動を後にする」

### 呪文の基本順序

```
1. 情報収集（凝視・回収・蝙蝠ETB）
    ↓ 情報を得る
2. 判断
    ↓ 何が正解か決まる
3. 不可逆な行動（除去・エスカレート・デルブ）
```

### 蝙蝠の追放先選択

**原則：「抜いたカードが戻る世界線で最も痛くないものを抜く」**

- ✗ 打ち消しを抜く → 安全に見えるが、相手が蝙蝠を除去する動機が高い（戻れば裏目最大）
- ✓ 除去札を抜く → 蝙蝠の生存率自体が上がり、戻っても即座の裏目になりにくい

**実例**：Match 17 G3 — 論争を抜いた→相手が白行進で蝙蝠除去→論争復帰→鏡割り打消し。白行進を抜いていれば蝙蝠除去手段自体が減り、論争3マナ構えの拘束をかけられた。

### 蝙蝠がカードを保持中の呪文順序

蝙蝠が打ち消しを追放中 → **蝙蝠が除去される前にキー呪文を通す**。蝙蝠除去→打ち消し復帰→打ち消しの順で裏目る。

## 原則4：資源管理 —「希少資源を特定し、それを守る」

局面ごとに希少な資源が変わる。**今何が希少かを特定し、それを守る行動を取る。**

| 局面 | 希少資源 | 守り方 |
|------|---------|--------|
| 対アグロ序盤 | **ライフ** | 合流点タップイン検討、除去優先、絆魂付与急ぐ |
| 対ミッドレンジ中盤 | **墓地のKWドナー** | 霊柩車即除去、侵入者排除 |
| 対コントロール長期戦 | **脅威の枚数** | 1体ずつ展開、評決後にリビエン |
| 全変身後 | **手札** | ハンデスで相手の回答を先に落とす |
| シェオル定着後 | **ライフ（ドローが裏目）** | 幽愁{U}{U}ルーティング回避、カヴァエロ着地急ぐ |

**実例**：Match 7 G3 — シェオル定着後に幽愁{U}{U}ルーティング（2ドロー＝4点ロス）を使おうとするのは希少資源の誤認。ライフが希少な局面でカードを引く行為自体がコスト。

## 原則5：マリガン基準 —「T4までに1軸が稼働するか」

### キープ/マリガン判定

| 手札の状態 | 判断 | 理由 |
|-----------|------|------|
| 土地2＋掘り＋勝ち手段 | **キープ** | 標準 |
| 土地3＋寓話＋KWドナー | **キープ** | 寓話第2章でドナー捨て→掘り変換 |
| 土地2＋凝視×2（回収なし） | **条件付き** | 凝視はトップ操作可だが土地を手札に加えられない |
| 土地1＋凝視のみ（回収なし） | **マリガン** | 凝視で土地は拾えない |
| 土地0 | **即マリガン** | — |

### 凝視と回収の機能差（マリガン判断の核）

| | 凝視（Otherworldly Gaze） | 回収（Grisly Salvage） |
|---|---|---|
| 土地を手札に加えられるか | ✗ | ✓ |
| T1から使えるか | ✓（{U}） | ✗（{B}{G}、T2） |
| 墓地に送る枚数 | 3枚（FB込み6枚） | 4枚 |
| トップ操作 | ✓（サーヴェイル） | ✗ |

→ **1土地キープは回収必須**。凝視だけでは土地にたどり着けない。

## サイドボード：変身深度の3段階

### 判断フロー

```
相手がRiP/力線を使うか？
  ├─ YES → 全変身（魂剥ぎ4＋河蛇4 OUT）
  └─ NO → 墓地対策はどの程度か？
              ├─ 霊柩車＋侵入者＋真っ白 厚め → 部分変身（魂剥ぎ2＋河蛇2 OUT）
              ├─ 霊柩車程度 → 部分変身 or 変身なし
              └─ なし（イゼプロ・赤単） → 変身なし（除去入替のみ）
```

### 偵察→調整の原則

G2でサイドの深さを仮決定し、**G2で相手の墓地対策量を偵察**、G3で変身深度を再調整する。

**実例**：Match 16（vs ゴルガリ）
- G2：部分変身 → 真っ白（Go Blank）×3を確認、部分変身では中途半端
- G3：全変身に切り替え → 凝視トップ操作＋欺瞞素出しで勝ち

### 変身深度別のOUT/IN指針

| 深度 | OUT候補 | IN候補 |
|------|---------|--------|
| **変身なし** | 運び手、幽愁、蛮行（対アグロ） | プッシュ3枚目、危難の道、選別、蛮行2枚目 |
| **部分変身** | 魂剥ぎ×2、河蛇×2、蝙蝠 | NDA×3、ハンデス、苦々しい勝利 |
| **全変身** | 魂剥ぎ×4、河蛇×4 | NDA×3、ハンデス全量、スキャム全量、幽愁追加 |
