# 対黒系ミッドレンジ（ラクドス）指針

2026-02-14 シミュレーションセッションから抽出。
主にラクドスミッドレンジを想定するが、ゴルガリ・オルゾフ等の「囲い＋侵入者＋蓋」構造を持つデッキに広く適用可能。

---

## 相手の三層構造を理解する

| 層 | カード群 | こちらへの影響 |
|---|---|---|
| 1. 手札破壊 | 思考囲い、強迫 | 魂剥ぎ/カヴァエロを直接追放。T1にほぼ確定で飛んでくる |
| 2. 墓地妨害 | 墓地の侵入者、真っ白、霊柩車 | KWドナーを選択的に剥がす。侵入者は護法＋毎ターン追放で最も厄介 |
| 3. 蓋 | シェオルドレッド、ドロスの魔神 | 侵入者をロックしても、接死絆魂4/5が4/4魂剥ぎと相打ち。ドロー課税でゲームを閉じる |

**構造的に最難関マッチアップ。** 1層＋2層は対処法があるが、3層のシェオルを超える手段がG1で薄い。

---

## 核心戦略：「呪禁4/4で侵入者をロックする」

### なぜ呪禁だけで十分か

- 呪禁4/4 vs 侵入者3/3 → **一方的に勝つ**
- 侵入者は攻撃できなくなる → **墓地追放エンジンが止まる＋クロックが止まる**
- 喉首狙い/致命的な一押し/パワー・ワード・キル → **すべて呪禁で無効**
- 飛行・絆魂・二段攻撃は「あれば嬉しい」だが、侵入者ロックには不要

### 理想形を追わない

| NG思考 | OK思考 |
|---|---|
| 河蛇＋アトラクサ＋サムトを全部墓地に揃えてから出す | **河蛇だけ墓地にあれば出してよい** |
| アトラクサが追放されたからプラン崩壊 | **呪禁だけの魂剥ぎが侵入者を完封する** |
| 速攻がないから1ターン待つ | **侵入者が1ターン余計に追放する方が損** |

## 墓地肥やしの原則：「追放レート < 供給レート」

侵入者は攻撃時1枚/ターン。**毎ターン3-5枚墓地に入れれば1枚抜かれても常にドナーが残る。**

個別のドナーを「守る」のではなく、**量で圧倒する**。

### 異世界の凝視（Otherworldly Gaze）の正しい評価

- 1マナ諜報3 ＋ FB{1}{U}で諜報3 = **計3マナで6枚を墓地に送れる**
- T1凝視 → T2-3にFBで追加3枚 = 序盤2ターンで墓地6枚
- 侵入者T3着地時点で墓地に6枚あれば、1枚追放されても5枚残る
- **T1凝視は対ラクドスで最優先のプレイ**

### 河蛇サイクリングのタイミング

サイクリング{U}：1マナで河蛇が墓地＋1ドロー。手札が減らない最高の呪禁セット。

**ただしタイミングに注意：**

| タイミング | 適切か | 理由 |
|---|---|---|
| T1（他に{U}の使い道がない） | △ | 凝視があるなら凝視を先に。ないなら可 |
| T2以降、{B}{B}と競合する | ✗ | 魂剥ぎキャストのマナを潰さない |
| **魂剥ぎキャスト直前、{B}{B}確保済み** | **◎** | 呪禁セット＋1ドロー＋デルブコスト追加を同時達成 |
| 凝視の諜報で河蛇が見えた時 | △ | 上に残してドロー→サイクリングの方が1ドロー分得 |

**原則：他にマナの使い道があるなら温存し、魂剥ぎを出すターンの余剰マナでサイクリング。**

## 最速T2魂剥ぎライン

理論上、対ラクドスでも問答無用で蓋をかけられる最速パターン。

```
T1: {U}が出る土地（闇滑り等）→ 凝視
    → 諜報3枚を問答無用で全部墓地に置く
    → 墓地: 3枚 + 凝視自身 = 4枚

T2: {B}{B}が出る土地配置（闇滑り+湿墓, 闇滑り+始まりの町 等）
    → 魂剥ぎキャスト: 探査4枚追放 + {B}{B}
```

**要求手札：** 凝視 + 魂剥ぎ + T1に{U}の土地 + T2に{B}{B}の土地配置（2枚）= 手札4枚を指定

**KWは諜報3枚の中身次第。** 河蛇が落ちれば呪禁、落ちなければバニラ4/4。ただし**T2の呪禁4/4はラクドスミッドのどの除去パターンより速い。** 囲いで魂剥ぎを抜かれなければ成立する。

**囲い裏目：** T1に凝視を先に唱えるので、囲いが後だと魂剥ぎが見えて抜かれる。相手のT1囲い（先手）は凝視より先に解決される → 手札の魂剥ぎが見えて追放される。**後手では成立しにくい（相手が先手T1囲いの場合）。先手なら現実的。**

## 大洞窟のコウモリ（Deep-Cavern Bat）の対ラクドス運用

### T2蝙蝠の価値

- ETBで相手の手札を見て、**侵入者 or 喉首を一時追放**
- 侵入者を追放 → T3の墓地追放を1ターン遅延
- 喉首を追放 → 魂剥ぎ着地の安全確保
- **掘りが手札にない時の「情報＋妨害」として特に有効**

### 追放先の原則（対ラクドス固有）

| 相手の手札に見えたもの | 追放先 | 理由 |
|---|---|---|
| 侵入者＋喉首 | **侵入者** | 墓地追放エンジンの遅延が優先。喉首は呪禁で無効化できる |
| 侵入者のみ | **侵入者** | 一択 |
| 喉首＋シェオル | **シェオル** | 呪禁で喉首は無効だが、シェオルは呪禁を無視して盤面を支配する |
| 寓話＋除去 | **除去** | 蝙蝠の生存率を上げる。寓話は遅いので許容 |

## 幽愁（Wistfulness）素出しによる除去ベイト

5マナ6/5。ETB（置物追放 or ルーティング）が腐らない。

**対ラクドスでの役割：**
- **喉首/無情な行動の的になる** → 後続のカヴァエロ/魂剥ぎが安全に着地
- 6/5は侵入者3/3を一方的に取れる
- 除去されても5マナ相当のテンポ交換で喉首（2マナ）を吐かせているので実質得
- **ただしT5到達が必要。** ライフが10を切っている場合は間に合わない可能性

## ゲームプラン概要

### G1の優先順位

```
1. T1凝視で墓地を肥やし始める
2. 河蛇を温存 → 魂剥ぎキャスト直前にサイクリング
3. 呪禁だけの魂剥ぎで侵入者をロック（理想形を待たない）
4. 侵入者ロック後、掘り継続でKWを追加 or カヴァエロで追撃
5. シェオル着地前に殴り切るか、苦々しい勝利/カヴァエロコピーで対処
```

### シェオル着地後の対処（G1で使える手段）

| 手段 | 条件 | 評価 |
|---|---|---|
| カヴァエロ→シェオルコピー（相手墓地から） | 相手の墓地にシェオルがある＝一度除去済み | 状況限定 |
| 致命的な一押し（リボルトMV4） | リボルト達成が必要 | 宝物消費や蝙蝠死亡で達成可能 |
| 蛮行エスカレート（-2/-2 + ドレイン） | 4/5に-2/-2は倒せない | ✗ |
| 戦闘（接死付き魂剥ぎ） | アトラクサが墓地にある必要 | アトラクサ追放されがち |

→ **G1でシェオルを超える手段が構造的に不足。G2以降は苦々しい勝利が必須。**

### G2以降のサイドプラン

侵入者＋真っ白程度（RiP/力線なし）→ **部分変身**

- **OUT候補：** 運び手、幽愁1、凝視1（掘り過多を調整）
- **IN候補：** 思考囲い、苦々しい勝利、強迫、蛮行2枚目

シェオルを先に落とすハンデス＋着地後の確定除去で3層目に対抗する。

## キープ基準（対ラクドス固有）

| 手札パターン | 判断 | 理由 |
|---|---|---|
| 土地2＋凝視＋魂剥ぎ | **キープ** | T1凝視→T2-3魂剥ぎの最速ルート。囲いで魂剥ぎ抜かれても凝視FBで掘れる |
| 土地2＋凝視＋カヴァエロ | **キープ** | 囲いでカヴァエロ抜かれても凝視で魂剥ぎを探せる |
| 土地2＋回収＋勝ち手段 | **キープ** | 回収が土地保険＋掘り |
| 土地2＋掘り0＋蝙蝠 | **マリガン** | 蝙蝠で妨害できても軸が成立しない |
| 土地2＋凝視×2（勝ち手段なし） | **条件付きキープ** | 6枚見れるので勝ち手段に触れる確率は高い。ただし回収なしで土地が止まるリスク |
| 土地5＋ | **マリガン** | 掘りも脅威も足りない |

## 未解決課題

- **シェオル着地後のG1勝率**：構造的に不利。苦々しい勝利のメイン昇格を検討する価値あり
- **ドロスの魔神への対処**：放置で油切れを待つか、苦々しい勝利か。相手のデーモンSBで油補充されるリスク
- **真っ白（Go Blank）への対応**：侵入者と異なり一括追放。速度で先行するか、囲いで先に落とす
- **G2-3の変身深度**：ラクドスはRiP/力線がないので全変身は過剰。部分変身の最適なOUT/INは実戦で詰める
