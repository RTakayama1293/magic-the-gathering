# 判断の層ごとの知見

最終更新: 2026-10-31（たたき台）

勝率を上げる判断を、取り組み方からマナの支払い方まで11の層に分け、リポジトリにある知見を層ごとに並べた。知見の出どころは、トッププロの発言（`notes/pro_thinking.md`）、戦績DB（`notes/play_learnings.md`、`notes/strategy_inventory.md`）、ユーザーの方針、数学的な事実の4つ。知見の少ない層は「空白」として書いた。

## 根拠の表記

| 表記 | 意味 |
|---|---|
| プロ一次 | 本人の記事か、本人の発言を直接引用したインタビュー。出典URLは `notes/pro_thinking.md` |
| プロ二次 | 第三者のまとめ、検索要約だけ、本人の記憶による引用 |
| DB #n | 戦績DBのMatch #。試合数を書く |
| ユーザー | ユーザーが決めた方針 |
| 数学 | 計算で確かめられる事実 |
| 仮説 | Claudeの推論。裏付けがない |

## 0. 取り組み方

| 知見 | 誰・根拠 |
|---|---|
| 負けたら、技術的なミスと判断、精神面、SBと構築、デッキ、運の順に原因を調べる。運はほかを調べ尽くしてから見る | Reid Duke（プロ一次） |
| 負けは常に自分の実力のせいと考える。勝った試合でも運の要素を分けて考える | 原根健太（プロ一次） |
| 練習は時間数より、その時間から何を持ち帰るかで決まる。疲れたまま、ほかのことをしながらの練習はしない | Reid Duke（プロ一次） |
| 強い相手と戦わないと自分の弱点に気づけない | 八十岡翔太（プロ一次）、原根健太（プロ一次） |
| 本番に近い形で練習する | 原根健太（プロ一次） |
| 各ゲームに一言のメモを残す。対戦前に対面の展開を想像し、対戦で確かめる | Lucas Esper Berthoud（プロ一次） |
| 負けたデッキでも、良かった部分を拾う | 市川ユウキ（プロ一次） |
| マジックの基礎（盤面の判断、マリガン、戦闘）はリミテッドで身につく | 八十岡翔太（プロ一次） |
| 結果ではなく、その時点で見えていた情報での期待値で判断を評価する | ユーザー（CLAUDE.md） |
| 試合数が少ないうちの勝率は幅が広い（10勝10敗で30%〜70%） | 数学（`notes/decision_criteria.md` 2章） |

## 1. 大会と形式の選択

| 知見 | 誰・根拠 |
|---|---|
| 相手の履歴から使うデッキを読む「人読み」は、リーグ戦では使えるが、誰と当たるか分からない大会では使えない | 佐藤レイ、八十岡翔太（プロ一次） |
| デッキリスト公開制の大会では、相手が単体除去を自由に撃てるので、防御の呪文の価値が上がる | 行弘賢（プロ一次） |
| 自分のプレイ速度で時間内に終えられないデッキは使わない | PVDDR（プロ一次） |

空白: Arenaのラダー（Bo1とBo3）と紙の大会（MITQなど）で何を変えるかについての知見はない。ユーザーと決める論点として `notes/decision_criteria.md` 5章に置いてある。

## 2. メタの読み

| 知見 | 誰・根拠 |
|---|---|
| 使用率12%と8%のデッキでは当たる確率にほとんど差がない。使用率20%を超えるデッキがあるときだけメタを意識する | 八十岡翔太（プロ一次） |
| 一強の環境では、そのデッキを使うか、そのデッキに強いデッキを使う。一強をメタったデッキをさらにメタると失敗しやすい | 八十岡翔太（プロ一次） |
| メタを読むときに自分のデッキの好みを混ぜない | PVDDR（プロ一次） |
| 来るデッキの予想は部分的に外れる | Reid Duke（プロ一次） |
| 環境を定義しているカードと、環境が向かっている方向を理解する | 市川ユウキ（プロ一次） |
| メタの仮説を文章で書き、その仮説を覆せる要素を探す | Lucas Esper Berthoud（プロ一次） |
| GPの参加者は直前でデッキの構成をあまり変えない | 原根健太（プロ一次） |
| メタの資料は出典URLと集計期間のあるものだけを使う | リポジトリの決まり（`.claude/skills/meta-update/SKILL.md`） |

## 3. デッキ選択

| 知見 | 誰・根拠 |
|---|---|
| どのデッキを選ぶかより、選んだデッキをどれだけうまく使えるかが大事 | Reid Duke（プロ一次）、八十岡翔太（プロ一次） |
| 練度の中身は、主要な対面との相性、SBとキープの基準、ミラーマッチの勝ち方を理解していること | 八十岡翔太（プロ一次） |
| ミラーマッチで勝つ手段があることは、デッキを選ぶ理由になる | 八十岡翔太（プロ一次） |
| 全部の対面で45〜55%の、極端な負け方をしにくいデッキを選ぶ。1つでも勝てない相手がいると優勝できない | 原根健太（プロ一次）、PVDDR（プロ一次） |
| 特定の1デッキにだけ負けて残りに勝つデッキを選ぶ | 行弘賢（プロ一次、2018年）。上の行と逆の考え方 |
| Arenaの勝率は広い相手との数字なので、そのままデッキ選択に使わない。勝率が高い理由を理解してから使う | 覚前輝也、行弘賢（プロ一次） |
| 強いデッキの条件は、マリガンに強い、ぶん回りがある、長期戦に強い | 渡辺雄也（プロ一次） |
| 結果が出ているデッキは、メタが実際に変わるまで手放さない | Brad Nelson（プロ一次） |
| チームのリストと勝率データを信頼し、練習で使っていないデッキを使う | 原根健太（プロ一次）。練度を優先する考え方と逆 |
| デッキ選択で好みを優先しすぎない | 原根健太（プロ一次）、市川ユウキ（プロ一次） |

## 4. 構築

### 4-1. 勝ち筋とデッキの骨格

| 知見 | 誰・根拠 |
|---|---|
| 同じ資源を使って勝つ手段が複数あるのは強みとして扱う。1ゲームの中でどれを使うかはその場で選ぶ | ユーザー（2026-10-31） |
| メインのカード種類を少なく、1種類の枚数を厚くし、汎用カードで固める | ユーザー（CLAUDE.md） |
| カード名ではなく、カードの種類（役割）でデッキのテンプレートを作る | 八十岡翔太（プロ一次） |
| 遅いデッキでも能動的な勝ち筋を持つ。長期戦で勝てると思い込んでいて実際は勝てないのが一番危ない | Reid Duke（プロ一次） |
| デッキはSB後の75枚の強さでも評価する | Reid Duke（プロ一次） |
| 環境初期は能動的なデッキを優先する | Lucas Esper Berthoud（プロ一次） |

### 4-2. カードの採否と枚数

| 知見 | 誰・根拠 |
|---|---|
| カードを入れる理由を、そのカードを使いたい具体的な場面と相手のカードで判断する | 原根健太（プロ一次）、渡辺雄也（プロ一次） |
| 枚数は実際に回して決める。2回唱えればほぼ勝つカードは3枚でよい | 八十岡翔太（プロ一次） |
| 枚数の判断は、経験から戻すこともある（3枚にしたカードを4枚に戻した） | 原根健太（プロ一次） |
| 「強い」「弱い」だけで採否を書かず、何に対して、どの場面で、何をするから採るのかを書く | リポジトリの決まり（`notes/decision_criteria.md` 3-3） |
| 除去と1対1交換になるカードを外し、1対2の交換を取り続ける構成にする | 高橋優太（プロ二次、検索要約のみ） |

### 4-3. マナベース

| 知見 | 誰・根拠 |
|---|---|
| 土地の枚数は回して決める（「土地は25枚では少ない」と判断した例） | 八十岡翔太（プロ一次） |
| 後手のSB後には土地を1枚減らすことも考える | PVDDR（プロ一次） |
| 色マナ源の必要枚数を超幾何分布で計算する | Frank Karsten（プロ二次。元記事は開けていない） |

空白: パイオニアのマナベース（ショックランド・ファストランド・始まりの町などの配分、基本土地の枚数）についての知見はない。

## 5. サイドボード

| 知見 | 誰・根拠 |
|---|---|
| SBは何に対して使うカードかを明確にする。対面を理解していなければ正しく組めない | 八十岡翔太、PVDDR（プロ一次） |
| SBは対面で選び、特定の1枚のカードで選ばない。各対面でメインから抜いてよいカードの枚数を数えてSBの枚数を決める | Reid Duke（プロ一次） |
| 1つのデッキ専用のカードより、幅広く対策できるカードを多く用意するほうが全体の勝率が上がる | 八十岡翔太（プロ一次） |
| SB後のゲームはG1より遅くなり、ドローや重い呪文の価値が上がる。元のプランが通らないならプランごと変える | Sam Black（プロ一次） |
| 相手のSB後のプランを予測して対策する | Sam Black、PVDDR（プロ一次） |
| 先手ではデッキの中心を残して入れ替えを少なくし、後手では対応寄りにする | PVDDR（プロ一次） |
| G2とG3の間でSBを見直す。予測されないことに価値があることもある | Reid Duke（プロ一次） |
| G1で得た情報と感じたことをSBに反映する | 原根健太（プロ一次） |
| SBで対策しすぎると、ほかのデッキに弱くなる | 中村修平（プロ一次） |
| SB後にデッキの戦い方を変えて相手の読みを外す | ユーザー（CLAUDE.md） |
| 対ゴルガリ・ミッドレンジでは、1対1交換から2対1交換に切り替えるSBで勝った | DB #108・#109（2試合） |

## 6. ゲームの入口（先手後手、マリガン、キープ）

| 知見 | 誰・根拠 |
|---|---|
| SB後のゲームはマリガンの基準も変える | PVDDR（プロ一次） |
| 対黒単デーモンのG3で先手後手の選択を誤り、攻守が逆になって負けた | DB #111（1試合） |
| 対アグロで除去が0枚の手札はマリガンした | DB #28（1試合、Soulflayer期） |

空白: 先手後手をどう選ぶか、キープの基準を対面ごとにどう決めるかの一般的な知見はない。八十岡翔太は「マリガンの判断」を基礎の一つに挙げているが、中身は語っていない。

## 7. ゲームプラン

| 知見 | 誰・根拠 |
|---|---|
| ゲームに勝つ・負けるには何が起きる必要があるかを常に把握する | PVDDR（プロ一次） |
| 相手のデッキに対して自分がコントロールなのかビートダウンなのかを決める | 渡辺雄也（プロ一次、SBの文脈） |
| ドロスの魔神を攻撃役にするかブロック役にするかを毎ターン決めてから動く | DB #107・#112（2試合） |
| 相手がこのデッキをライフゲインのデーモンデッキと誤認するので、デッキの正体を早く見せない | DB #102・#105（2試合） |

## 8. 局面の判断

| 知見 | 誰・根拠 |
|---|---|
| 選択肢があることにまず気づく。決める前に情報を集め、決める必要が来るまで待つ。うまい相手には選択肢を与えない | PVDDR（プロ一次） |
| 正解は1つと考えて最善のプレイを探す | 原根健太（プロ一次）。原根が引用したJon Finkelの言葉は原文未確認 |
| 100点のプレイがほぼ不可能なデッキでは、細かいミスの差で勝敗が決まる | 八十岡翔太（プロ一次） |
| 思考囲いでは、ゲームの構造を変えるカードを1対1の干渉呪文より優先して抜く | DB #59・#90・#108（3試合） |
| 対ゴルガリの思考囲いは、アナグマモグラの仔（Badgermole Cub）と名もなき都市の歩哨（Sentinel of the Nameless City）を優先して抜く | DB #108・#109の学び欄 |
| ドロスの魔神の油カウンターに反応する前に、自分と相手の残りターン数を数える | DB #107（1試合） |
| 変態変異（Metamorphic Alteration）を、相手の脅威を弱いクリーチャーのコピーにする疑似除去として使う | DB #56（1試合） |

## 空白の層を埋める方法（提案）

1. 層9（マナと手順）と層6（先手後手・マリガン）: トッププロやコーチの記事を、層を指定して調べ直す。今回の調査はデッキ選択とSBの発言が中心で、細かいプレイの記事を探していない
2. 層9と層10: ユーザーの対戦の振り返りで、マナの支払いや手順の誤りを見つけたら、層の番号を付けて `notes/play_learnings.md` に書く
3. 層1: Arenaのラダーと紙の大会で変える点を、ユーザーと決める
