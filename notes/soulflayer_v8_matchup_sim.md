# 魂剥ぎV8の対面別の計算（ゴルガリ、脂牙、異形化）

作成: 2026-11-01。計算は `tools/v8_golgari_sim.py` と `tools/v8_unfair_sim.py`（乱数の種を固定しているので、実行すると同じ数字が出る）。どちらも単純な手順で両者を動かしたもので、数字は構成やプランどうしの比較にだけ使う。実戦で確かめるまで、すべて仮説として扱う。

こちらのメインは `notes/soulflayer_v8_proposal.md` の第7版（魂剥ぎ4、スーペリア・スパイダーマン4、縞カワヘビ4、サムト3、運び手2、アトラクサ2、忌まわしい回収4、メカの天才4、幽愁2、ダイナの導き2、異世界の凝視1、苦々しい勝利3、致命的な一押し3、土地22）。

## 1. ゴルガリ・ミッドレンジ

### 計算の方法

- 相手はMTGGoldfishの平均リスト（2026-11-01取得）。メインは、アナグマモグラの仔4、墓地の侵入者4、デリアン・フェル教授4、黙示録、シェオルドレッド3、致命的な一押し4、突然の衰微3、苦々しい勝利2、思考囲い4、強迫1、選別の儀式2、不浄な別室4、羅利骨灰1、土地24
- 相手のSB後は、致命的な一押し4・選別の儀式2・羅利骨灰1・突然の衰微1を抜き、未認可霊柩車3・真っ白2・戦略的裏切り3を入れる
- 相手は、こちらの一番強い脅威から順に、撃てる除去を撃つ。こちらの墓地に勝ち筋の材料（運び手・サムト・アトラクサ・縞カワヘビ）があれば、墓地対策を使う
- どちらもブロックせず、毎ターン全員で攻撃する。12ターンで決着しなければ引き分け（0.5勝）
- 各4000ゲーム。勝率の誤差はおよそ±1.5ポイント

カードテキストから分かること: 相手の致命的な一押し（マナ総量2以下）と突然の衰微（マナ総量3以下）は、魂剥ぎ（マナ総量6）やスーペリア・スパイダーマンのコピー（コピー先のマナ総量）を破壊できない。相手がこちらの大型の脅威に撃てるのは、苦々しい勝利2とデリアン・フェル教授4の-3と、SBの戦略的裏切り・絶滅の契機・絶望招来に限られる。呪禁の魂剥ぎには、苦々しい勝利とデリアン・フェル教授も撃てない。

### 読み方

1. 相手が墓地対策を入れると、勝率は約50%から約32%に下がる
2. 運び手を抜くと5〜6ポイント下がった。計算では、全体リアニメイトで戻る自分の墓地のクリーチャーが、相手の墓地のクリーチャー（アナグマモグラの仔・墓地の侵入者・黙示録、シェオルドレッド）より強い場面が多かった。第8版で「運び手は相手の墓地のクリーチャーも戻すので抜く」としたのは、計算と合わない
3. 墓地の侵入者と黙示録、シェオルドレッドは、それぞれ2〜3ポイント上げた。相手の大型の除去（デリアン・フェル教授など）が魂剥ぎやスーペリア・スパイダーマンに使われると、黙示録、シェオルドレッドが残る場面がある
4. 思考囲いと突然の衰微は、ほとんど上げなかった。思考囲いは2点を払い、相手の墓地対策を1枚しか抜けない。突然の衰微は、計算では未認可霊柩車の1枚目を破壊しても次の墓地対策が来る
5. 推奨: ゴルガリ戦のSBは「墓地の侵入者2・黙示録、シェオルドレッド2を入れ、致命的な一押し3・異世界の凝視1を抜く」。運び手とサムトは残す

### この計算に入っていないこと

- ブロック。黙示録、シェオルドレッド（接死）や墓地の侵入者が壁になる場面と、こちらの飛行クリーチャーが止められない場面の差
- 相手のSB後のプランの読み合い。相手が墓地対策を入れない場合のプランは別に計算した（第8版のプランで先手50.3%）

## 2. アブザン脂牙とラクドス異形化

### 計算の方法

- 相手の理想ムーブは `tools/v8_unfair_sim.py` の冒頭に書いた。脂牙は機体を墓地に置き、大牙勢団の総長、脂牙で戻して攻撃する。異形化は、トークンを対象に異形化を唱えるか、捨てた大型クリーチャーをゾンビ化で戻す
- 相手はこちらに干渉しない（思考囲いだけ撃つ）。こちらはブロックしない
- 同じシャッフルで、妨害を使う回と使わない回を比べる（`notes/soulflayer_v8_interaction_sim.md` と同じ方法）。「間に合う」は、相手のキルより先に自分の勝ち筋が成立した割合

注意: 計算上の脂牙のキルターンは平均6.4〜6.8ターンで、実際の脂牙（3〜4ターン目に攻撃を始めることが多い）より遅い。平均リストのうち、計算に入れていないカード（象徴学の教授の学習で引く教訓など）が7枚あるため。「間に合う」の割合は実際より高く出ている。

### 結果（自分が先手）

|---|---|---|---|---|
| メインのみ（苦々しい勝利3・致命的な一押し3） | 6.41→6.95 | 82%→85% | 7.45→7.64 | 89%→92% |
| 思考囲い3 | 6.41→7.20 | 82%→87% | 7.45→7.76 | 89%→92% |
| 真っ白2 | 6.41→7.28 | 81%→86% | 7.45→7.81 | 88%→92% |
| 戦略的裏切り2 | 6.41→7.16 | 81%→86% | 7.45→7.78 | 88%→92% |
| 魂標ランタン1 | 6.41→7.12 | 81%→86% | 7.45→7.70 | 88%→92% |
| 墓地の侵入者2 | 6.41→7.18 | 80%→85% | 7.45→7.71 | 88%→91% |
| 第8版SBの組み合わせ（思考囲い3・真っ白2・戦略的裏切り2・ランタン1） | 6.41→7.76 | 78%→89% | 7.45→8.04 | 85%→91% |

後手の結果も同じ傾向だった（`python3 tools/v8_unfair_sim.py` で出る）。

### 読み方

1. どの妨害も、平均では基準（相手を遅らせるターンが自分の遅れ以上）を満たした。自分の勝ち筋の遅れは0.1ターン以下
2. 脂牙には、真っ白・戦略的裏切り・ランタンで相手の墓地の機体を追放すると、相手のキルターンが0.7〜0.9ターン遅れた。メインの苦々しい勝利を構えて脂牙を戦闘前に破壊する動きも、撃てたゲームの88%で基準を満たした
3. 異形化には、どの妨害も0.2〜0.4ターンしか遅らせなかった。異形化はトークンを対象にするので、相手の墓地の対策では止まらない。思考囲いが基準を満たしたのは、撃ったゲームの41〜42%だった
4. SBを組み合わせると、脂牙で「間に合う」が11ポイント、異形化で6ポイント上がった

### この計算に入っていないこと

- 相手の除去やハンデスによるこちらへの干渉（思考囲い以外）
- 恐怖を喰うもの、ヴァルガヴォスが出ると、こちらの墓地に行くカードは追放される（テキスト）。計算ではこの間の墓地の増加を止めている
- 運び手の全体リアニメイトで相手の墓地のクリーチャーが戻る影響

## 3. SBへの反映

- ゴルガリ戦: 「墓地の侵入者2・黙示録、シェオルドレッド2を入れ、致命的な一押し3・異世界の凝視1を抜く」に直す。運び手とサムトは残す
- 脂牙・異形化戦: 第8版のプラン（思考囲い3・真っ白2・戦略的裏切り2・魂標ランタン1を入れる）のまま。運び手を抜くかは、この計算では確かめていない
- 突然の衰微2枚は、ゴルガリ戦の計算では効果が出なかった。5色ロナのジェスカイの隆盛や果敢デッキの嵐追いの才能への回答として残すかを、次の計算で確かめる
