# 魂剥ぎV8の妨害カードのシミュレーション

作成: 2026-11-01。計算は `tools/v8_interaction_sim.py`（乱数の種を固定しているので、実行すると同じ数字が出る）。

ユーザーが決めた基準は「妨害で相手の理想ムーブのキルターンを、妨害に使ったターン以上に遅らせられるか」。この基準で、メインの妨害の候補を比べた。

## 1. 結論

1. 相手の果敢デッキ（赤単果敢、イゼット果敢）に対して、どの妨害も平均では基準を満たした。自分の展開を先にして余ったマナで除去を撃つ使い方なら、自分の勝ち筋が成立するターンはほとんど遅れない。相手のキルターンは平均で0.3〜1.9ターン遅れた
2. 1ゲームずつ見ると、妨害を撃ったゲームのうち、相手を自分より長く遅らせたのは28〜72%だった。残りのゲームでは、除去を撃っても相手のキルターンが変わらなかった
3. 相手を最も遅らせたのは1マナの除去（致命的な一押し、報いの呪詛（Requiting Hex））だった。2マナの除去（絶望的批評（Terminal Criticism）、最後の喘ぎ（Last Gasp）、セオリクスの魔除け（Theorix Charm））が次で、思考囲いと大洞窟のコウモリが最も小さかった
4. 妨害7枚を墓地肥やし7枚に替えた構成と比べると、先手では差がほとんど無く、後手では妨害を入れたほうが「相手のキルより先に勝ち筋が成立する」割合が5〜8ポイント高かった

## 2. 計算の方法

### 相手の理想ムーブ

MTGGoldfishの平均リスト（2026-11-01取得）を使った。

- 赤単果敢: https://www.mtggoldfish.com/archetype/pioneer-mono-red-prowess
- イゼット果敢: https://www.mtggoldfish.com/archetype/pioneer-izzet-prowess

相手は次の順で動く。

1. 毎ターン土地を置き、熊野と渇苛斬の対峙（Kumano Faces Kakkazan）とクリーチャーを唱える
2. こちらが除去を撃つ場面を挟む
3. 残りのマナで、嵐追いの才能（Stormchaser's Talent）、手札入れ替えの呪文、巨怪の怒り（Monstrous Rage）を唱え、噴出の稲妻（Burst Lightning）を顔に撃つ。果敢は呪文1つごとに+1/+1
4. 召喚酔いでないクリーチャー全員で攻撃する。こちらはブロックしない

こちらのライフは、ショックランドなどで払う分を見込んで18から始めた。

### 自分の動き

`notes/soulflayer_v8_proposal.md` の53枚（勝ち筋と墓地肥やしと土地）に、妨害7枚を足した60枚で回した。妨害の使い方は2通りある。

| 使い方 | 中身 |
|---|---|
| dev | 自分のターンは展開を先にする。余ったマナで、相手のターンの戦闘前に除去を撃つ |
| int | 相手のクリーチャーがいれば、自分のターンの最初に除去を撃ってから展開する。余ったマナでも相手のターンに除去を撃つ |

どちらの使い方でも、思考囲いは2ターン目まで、大洞窟のコウモリは3ターン目までに唱える。除去は、果敢を持つクリーチャーなど打点の大きいものから狙う。

### 比べ方

同じシャッフルで2回ゲームを回した。1回目は妨害カードを使わずに手札に残し、2回目は使う。1ゲームごとに次の2つを出した。

- ΔK: 相手のキルターンの遅れ
- ΔG: 自分の勝ち筋が成立するターンの遅れ

ΔK > ΔG なら、「妨害に使ったターンより長く相手を遅らせた」と数えた。各構成4000ゲームで、割合の誤差はおよそ±1.5ポイント。

### 結果の読み方

- 自分の勝ち筋のターン（ΔG）が妨害を使うと早くなるのは、苦々しい勝利の追加コストで手札の運び手などを墓地に捨てるため
- 思考囲いと大洞窟のコウモリの効果が小さいのは、相手の手札から1枚抜いても、残りのクリーチャーと火力で同じくらいのダメージが出るため。コウモリは噴出の稲妻などで除去され、追放したカードが相手の手札に戻る
- 先手で妨害なしの構成と同じ割合になったのは、墓地肥やしを7枚足すと自分の勝ち筋が平均0.4ターン早くなり、除去で相手を遅らせるのと同じくらいの効果になるため

## 4. この計算に入っていないこと

数字は構成どうしの比較にだけ使う。

1. **こちらはブロックしない。** スーペリア・スパイダーマンや運び手で戻したクリーチャーも、相手の攻撃を止めない。実際は勝ち筋が成立した後も、相手の残りの打点を止める必要がある
2. **「勝ち筋が成立する」は、勝ちを意味しない。** 魂剥ぎやコピーが戦場に出たターンを数えている。相手を倒すまでにさらに数ターンかかる
3. **相手は大洞窟のコウモリ以外のこちらのクリーチャーを除去しない。** 噴出の稲妻を顔に撃ち続ける前提なので、相手のキルターンは早めに、こちらの勝ちは早めに出る
4. **ゴルガリ・ミッドレンジ、ニクス・ランプ、ジャンド・サクリファイスは計算していない。** 致命的な一押しと報いの呪詛はマナ総量2以下しか破壊できない。絶望的批評は青か赤のクリーチャーしか破壊できない。ゴルガリの墓地の侵入者（マナ総量3）や黙示録、シェオルドレッド（マナ総量4）には撃てない（テキスト）
5. 色、タップインの土地、マリガン、熊野と渇苛斬の対峙の2章、学術論争（Academic Dispute）の学習は計算に入れていない

## 5. 構築への使い方（仮説）

- 果敢デッキ相手には、メインの除去を1マナのものに寄せると相手を最も遅らせられる
- ゴルガリには1マナの除去が当たらないものが多いので、苦々しい勝利（何でも破壊できる）を残す
- 案: メインの除去を「致命的な一押し4＋苦々しい勝利3」にし、報いの呪詛をSBに置く。思考囲いと大洞窟のコウモリは、果敢デッキ相手のSBから外す
- 次に計算すること: ゴルガリ・ミッドレンジの理想ムーブ（デリアン・フェル教授（Professor Dellian Fel）と黙示録、シェオルドレッドで押す展開）と、墓地対策カードを撃たれた場合の自分の遅れ
